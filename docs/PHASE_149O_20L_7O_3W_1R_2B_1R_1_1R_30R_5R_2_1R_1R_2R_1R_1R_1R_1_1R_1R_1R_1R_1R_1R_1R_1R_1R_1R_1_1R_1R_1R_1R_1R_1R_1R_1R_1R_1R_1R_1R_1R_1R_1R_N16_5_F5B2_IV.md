## B2 Defect / Repair Reconstruction (independent)

Read from primary source, not from the predecessor's report: `src/pcae/core/hpac_protected_admin_writer.py`, function `_detect_caller_module(explicit)`. The N16-5-F-5-B2-IMPL repair removed the caller-controlled early return (previously: `if explicit is not None: return explicit`) and replaced it with `del explicit` followed by an unconditional `inspect.stack()` walk that returns `frame.f_globals.get("__name__")` for the first frame beyond the factory call whose name is not `None`/`<locals>`/`contextlib`. All four privileged factories (`production_writer`, `certification_writer`, `recognized_certification_read_authority`, `mint_protected_presentation_evidence_writer`) call this one shared primitive identically.

`docs/contracts/HPAC_PRODUCTION_PROTECTED_ADMIN_WRITER_ANCHOR_CONTRACT.md` §32 defines factory-consumer recognition as "the importing / calling **source module** — a build-time / import-time fact," explicitly not a caller-asserted string. This predicate is shared by reference across §33/§33A/§33B for all four factories.

**Independent finding: the repair is insufficient against this exact contract clause.** `frame.f_globals["__name__"]` is not a build-time/import-time fact tied to `sys.modules` registration — it is an ordinary, mutable dict key on a Python frame's globals namespace, and any in-process caller can construct a scratch frame with an arbitrary `__name__` via `exec(code, {"__name__": "<any string>", ...})` with no special privilege, no filesystem access, and no `sys.modules` registration. The repair therefore relocated the trusted input from an explicit, disclosed keyword argument (`_caller_module`) to an equally caller-controllable implicit global, rather than eliminating caller-controlled recognition, as required.
